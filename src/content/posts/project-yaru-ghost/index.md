The theme you're looking at. A Ghost theme inspired by Ubuntu 24.04: Yaru dark surfaces, a terminal prompt, code blocks as GNOME windows and the Ubuntu orange only in the details.

<figure class="kg-card kg-image-card kg-width-wide kg-card-hascaption"><img src="/images/project-yaru-ghost/home.png" class="kg-image" alt="The Yaru home page with the terminal prompt and the numbered post list." width="1440" height="900"><figcaption>The Yaru home page with the terminal prompt and the numbered post list.</figcaption></figure>

## Highlights

- GTK-style tabs in the navigation, with the current item marked in orange.
- Search posts by title right in the prompt, with a blinking cursor.
- Category pills on the blog and tag pages.
- Syntax highlighting with two palettes: Ubuntu terminal and ray.so.
